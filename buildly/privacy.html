プライバシーポリシー

アプリ名：Buildly／最終更新日：2026年10月30日

本プライバシーポリシーは、Buildly（以下「本アプリ」といいます）の提供にあたり、利用者の情報をどのように取り扱うかを説明するものです。本アプリは、アプリ開発者ご本人が、自らのアプリ群のビルド・リリース・実績を確認するためのコンソールアプリです。

1. 本アプリが収集する情報

本アプリは、利用者の個人情報を収集しません。アカウント登録は行いません。氏名、住所、電話番号、メールアドレスなどの連絡先情報は収集しません。位置情報、端末内の写真、連絡先、カメラ・マイクのデータは収集しません（これらの権限も使用しません）。広告識別子などを用いた行動追跡（トラッキング）は行いません。解析ツールによる利用状況の収集も行いません。当方のサーバーへ利用者のデータが送信されることはありません。

2. 端末内に保存されるデータ

本アプリは、機能の提供のために次のデータを、利用者の端末内のみに保存します。

  • 入力したアプリのアイディア（アプリ名、概要、カテゴリなど）
  • 設定（スナップショットの取得先URL、対象リポジトリの設定）
  • 取得したスナップショットデータ（ご自身のアプリ群の状態・実績）のキャッシュ

これらが当方や第三者へ送信されることはありません。設定画面の「保存データを初期化」からすべて削除できます。アプリを削除すると、端末内のデータも削除されます。

3. GitHub トークンの取り扱い

ビルド状況の確認とビルド起動の機能を使う場合に限り、利用者ご自身の GitHub トークンを設定画面から入力できます。トークンは端末内の安全な保存領域（SecureStore）にのみ保存され、GitHub の API（api.github.com）との通信にだけ使用します。当方のサーバーへ送信されることはなく、当方がトークンを受け取ることもありません。トークンはいつでも設定画面から削除できます。

4. 通信先について

本アプリの通信は、(1) 利用者が設定したスナップショット取得先URLからのデータ取得と、(2) 上記の GitHub API との通信に限られます。いずれも利用者の設定・操作に基づくもので、表示されるデータは利用者ご自身のアプリに関するものです。

5. 第三者への提供

本アプリは利用者の情報を収集しないため、第三者への販売、貸与、提供は行いません。広告は表示しません。広告配信事業者への情報提供も行いません。

7. 本ポリシーの変更

本ポリシーを変更する場合は、本ページの掲載内容を更新し、変更後の内容を公表します。重要な変更を行う場合は、アプリ内での案内など、分かりやすい方法でお知らせするよう努めます。
