サポート

「Buildly」のサポートページです。

アプリについて

Buildly は、アプリ開発者が自分のアプリ群の状態をまとめて確認するためのコンソールアプリです。公開中・審査待ちなどの状態、最新ビルド、ダウンロード数やレビュー数、公開後30日の判定日までの残り日数を、ダッシュボードとアプリ一覧で確認できます。新しいアプリのアイディアを入力して書き出す機能や、GitHub Actions のビルド状況の確認と起動も行えます。アカウント登録は不要です。

使い方

ダッシュボード
登録アプリの総数、公開中・審査待ち・提出準備中の内訳、総ダウンロード数とレビュー総数、公開後30日判定が近いアプリ、直近の動きを確認できます。「最新を取得」で表示データを更新します。

アプリ一覧・詳細
各アプリの審査状態、最新ビルド番号、レビュー数、ダウンロード数、公開日と30日判定日、課金商品の状態を確認できます。

アイディア
新しいアプリのアイディア（アプリ名、概要、カテゴリ、テーマカラーなど）を入力して保存できます。保存したアイディアは JSON 形式で書き出し・共有できます。

ビルド
GitHub Actions の実行状況を表示し、ビルドを起動できます。この機能には、設定画面でご自身の GitHub トークンを入力することと、対象リポジトリの設定が必要です。未設定の場合は、その旨が画面に表示され、閲覧機能のみが動作します。

設定
スナップショットの取得先URLの変更と取得、GitHub トークンの設定・削除、リポジトリ設定、保存データの初期化が行えます。

よくある質問

Q. アカウント登録は必要ですか？
いいえ。登録なしで閲覧機能をお使いいただけます。ビルド機能を使う場合のみ、ご自身の GitHub トークンの入力が必要です。

Q. 料金はかかりますか？
無料です。アプリ内課金や広告はありません。

Q. GitHub トークンは安全ですか？
トークンは端末内の安全な保存領域にのみ保存され、GitHub の API との通信にだけ使います。当方のサーバーへ送信されることはありません。不要になったら設定画面からいつでも削除できます。

Q. 表示されるデータはどこから来ますか？
アプリに同梱されたスナップショット、または設定した取得先URLから取得したスナップショットを表示します。データの内容は、あなた自身のアプリ群の状態と実績です。

Q. 入力したアイディアや設定を消したい場合は？
設定画面の「保存データを初期化」からすべて削除できます。アプリを削除しても端末内のデータは削除されます。
